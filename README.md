## 🚀 How to Run

```bash

cd 01_basics

# Run a Python file
python3 01_hello_world.py
```

## 📝 Notes
- Complete modules in order (each builds on the previous)
- Read the comments inside each `.py` file — they explain everything
- Modify the code, experiment, and break things to learn!
